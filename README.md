## Suggested Folder Structure

Each topic has its own folder so that solutions can be added later without changing the tracker structure.

```text
striver-sde-sheet/
├── README.md
├── Arrays/
├── Linked-List/
├── Greedy/
├── Recursion-Backtracking/
├── Binary-Search/
├── Heaps/
├── Stack-Queue/
├── Strings/
├── Binary-Trees/
├── Binary-Search-Trees/
├── Graphs/
└── Dynamic-Programming/
```

You can keep your C++ solutions inside the relevant folder, for example:

```text
Arrays/
├── 01_Set_Matrix_Zeroes.cpp
├── 02_Pascals_Triangle.cpp
├── 03_Next_Permutation.cpp
└── ...
```
